# Agent Rules

- Before making changes, read [docs/tech-stack.md](docs/tech-stack.md) to understand the frontend and backend technologies in use.
- Follow the conventions in [docs/coding-conventions.md](docs/coding-conventions.md) when writing or modifying code.
- If a change introduces a new convention or technology, update the relevant doc in `docs/` to keep it accurate.
- Bootstrapping a new project from this template, end to end (copy, config, infra apply, deploy)? Use the `/bootstrap` skill (`.claude/skills/bootstrap/`) rather than running `bootstrap-project.py` or `infra/scripts/bootstrap-infra.sh` by hand.
